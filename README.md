# 豆苗学堂 · 少儿 AI 与计算机科普学习站

面向 6–12 岁儿童的纯静态科普网站：以「一滴水穿过南京城」为故事线，把抽象的计算机与 AI 知识放进花灯、城墙、画舫、云锦等本地场景里。零框架、零后端、零第三方依赖。

- 在线体验：https://wbydxx.github.io/doumiao-academy/
- 页面总数：40（首页 1 + 成就墙 1 + 课程 37 + 404 1）
- 内容规模：6 大关卡 / 25 课时（含第 0 课）/ 6 个互动游戏 / 6 套挑战测验

## 本地运行

方式一：直接双击 `index.html` 用浏览器打开。

方式二（推荐，避免个别浏览器对本地文件的限制）：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```


## 核心功能

1. **分幕式课件**：每节课按「开场 → 讲解 → 试一试 → 互动 → 小结」分幕，支持按钮、方向键、滑动、双击空白翻页；内容超长时自动转为幕内滚动。
2. **浏览器内 Python 运行器**：内置 Python 子集解释器，可编辑、运行、命中目标输出后即时判定，无需安装环境。
3. **游戏化激励**：雨花石积分、六关徽章、成就墙、进度持久化（localStorage 三层存储），支持进度导出 / 导入 / 重置。
4. **无障碍与移动适配**：语义化标签、键盘可操作、手机端手势翻页与响应式布局。

## 技术说明

- 纯 HTML5 + CSS3 + 原生 JavaScript（ES5 兼容写法），无构建步骤、无外部 CDN。
- 分幕引擎在运行时把章节内容重组为 deck/slide 结构，统一字号与滚动策略。
- 进度存储分三层：Driver 驱动层（localStorage / 内存兜底）、ObjectStore 对象桶、Repository 领域仓库。
- 代码运行器为教学用 Python 子集解释器（变量、运算、条件、循环、函数、f-string 等）。

## 浏览器兼容

Chrome / Edge / Firefox / Safari 近两年版本；手机端 iOS Safari 与 Android Chrome 均可正常使用。
