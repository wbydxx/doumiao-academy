用花灯数数

四盏花灯排一排，就是一台小小加法机。

四盏花灯排成一排，从左到右的分值是 8、4、2、1。

亮着的花灯把分值加起来，灭的算 0，不用管它。

灯语 0 1 0 1，就是 4 + 1 = 5，像做加法游戏！

为什么是 8、4、2、1

从右边数起，每一盏灯的分值都是它右边那盏的 2 倍：1 翻一倍是 2，2 翻一倍是 4，4 翻一倍是 8。

换成 2 的指数写，就是：1 = 2⁰，2 = 2¹，4 = 2²，8 = 2³——每往左挪一格，就翻一倍。

也因为每盏灯只有「亮、灭」两种状态，两盏灯能拼出 2×2 = 4 种组合，四盏灯就是 2×2×2×2 = 16 种，刚好从 0 数到 15，一个不落。

动手试一试

点亮花灯，拼出数字 5

现在的灯语

0 0 0 0

合起来是 0

点亮几盏花灯，试试拼出 5 吧！
