变量，就是贴了名字的箱子

想象你在快递站打包行李：每个箱子都要贴上标签，才知道里面装的是什么。程序里的「变量」就是这种贴了名字的箱子——标签上写 city，箱子里放 "南京"。

这一课你将学会：给箱子贴标签（赋值）、认出箱子里装的是文字、整数、小数还是"是/否"（数据类型），再用 f-string 把它们漂亮地打印出来。学完就动手改 3 段真代码！

先懂 4 个概念

变量 Variable

贴名字的箱子。Python 不用先打招唿，一个等号直接赋值就能用；想换内容，再赋一次就行。

city = "南京"

四种类型

str 文字："南京" ｜ int 整数：12 ｜ float 小数：3.5 ｜ bool 是非：True / False（首字母要大写）。

n = 12   s = "12"   f = 3.5

f-string 填空模板

引号前加一个 f，文字就变成填空题：{ } 里放变量或算式，运行时自动把结果填进去。

f"我 {age} 岁"

print()

程序员的调试望远镜：把内容打印到屏幕上。看不清程序在想什么时，就打印一行出来瞧瞧。

print("你好")

练 1 · 这段代码会怎样？

a = 5 b = "5" print(a + b)

Python 很严格：数字和文字不能直接相加，会抛出 TypeError。想拼在一起要用 f-string（f"{a}{b}" 得 "55"）或先转换（str(a) + b）。这一点它不像有些语言那样"悄悄帮你转"。

练 2 · age = "9" 和 age = 9 的区别是？

引号是文字的标志：type("9") 是 str，type(9) 是 int。类型不同，能做的事也不同——数字能加减乘除，文字能拼接。

练 3 · 这段代码输出什么？

name = "豆豆" print(f"你好，{name}")

f-string 的 { } 是填空位：运行时把变量的值填进去，花括号本身不会出现在结果里。别忘了引号前那个小写 f，少了它 { } 就只是普通文字。
