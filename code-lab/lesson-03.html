循环与函数

计算机的两大超能力：不厌其烦地重复（循环），以及把复杂动作打包成一句命令（函数）。

for + range 循环 def 函数与参数 return 返回值 循环 + 函数组合技
课前导读

一台「代工机器」和一条「绕圈跑道」

函数就像家里的豆浆机：放进豆子（参数），机器加工，倒出豆浆（返回值）。用 def 把它造好一次，以后喊一声名字就能用——不用每次重新造机器。

循环是绕圈跑道：for i in range(1, 6) 就是"从第 1 圈跑到第 5 圈"，range 数头不数尾，程序绝不偷懒也不多跑。这一课你将学会写循环、造函数，最后把两者组合起来，打磨出一批雨花石。

先懂 4 个概念

for + range 循环

range(1, 6) 依次给出 1、2、3、4、5——数头不数尾，终点不计入。只写一个数的 range(5) 则从 0 数到 4。

for i in range(1, 6):
    print(i)

def 函数与参数

用 def 把操作打包命名，随时调用。括号里的 name 是参数（进料口），调用时传什么它就收什么。

def greet(name):
    …
greet("波波")

return 返回值

return 负责交出结果（出料口）并立刻结束函数。没有 return 的函数像只响不回话的喇叭。

return "你好, " + name

DRY 原则

Don't Repeat Yourself——同一逻辑写一次到处调用，需求变了只改一处。真实程序就是循环里调函数、函数里套条件。

total = total + shine(i)

练 1 · 这个循环打印出什么？

for i in range(3): print(i)

range(3) 从 0 数到 2——数头不数尾。所以 i 是 0、1、2，共三行。程序员数数从 0 开始。

练 2 · 函数里的 return 是干什么的？

return 是函数的「出料口」：把结果交还给调用者，同时函数立刻收工。打印屏幕是 print() 的活，两者别搞混。

练 3 · 这段代码打印几行？

for i in range(2): print("你好")

range(2) 让循环跑 2 圈，每圈 print 一次，所以是 2 行。print 里没用到 i，i 只负责「数圈数」——这是循环最常见的用法：让同一句话重复 N 遍。
