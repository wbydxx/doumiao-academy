列表与遍历

一个变量只能装一个值？太慢了。列表是一列贴好序号的箱子，一次装下整条地铁线；遍历让程序挨个箱子查一遍。

列表 [ ] 索引从 0 数 for-in 遍历 append / len
课前导读

一整条地铁线，装进一个变量

报站屏上的「下一站：玄武门」，背后其实是一张站名列表：["下关", "玄武门", "鸡鸣寺"]。列表就像一排寄存柜，每个柜子有编号——程序员的编号从 0 开始数，所以第二站是 stations[1]。

这一课你将学会：建列表、按编号取站名、用 for 把整条线挨个报一遍，还能用 append 装新货、用 len 数件数。学完你就能指挥一段真正的地铁报站系统。

先懂 4 个概念

列表 List

方括号一装，多个值排队入住，逗号隔开。字符串、数字可以混装，顺序就是摆放顺序。

line = ["下关", "玄武门"]

索引：从 0 数

line[0] 是第 1 个，line[1] 是第 2 个。程序员从 0 开始数数——最后一个永远是「长度减 1」。

line[0]   # "下关"

for-in 遍历

for s in line: 让 s 依次变成列表里的每一项，循环体跟着跑——一列箱子挨个开一遍。

for s in line:
    print(s)

append 与 len

append(x) 在队尾加一件货；len(line) 数出共几件。一个负责「装」，一个负责「数」。

line.append("云锦")
len(line)   # 3

练 1 · 索引从几开始数？

stations = ["下关", "玄武门"] print(stations[0])

列表索引从 0 开始：stations[0] 是第 1 个「下关」，stations[1] 才是「玄武门」。整份练习里请把「第几个」和「索引几」分开——差 1 是新手最常见的 bug。

练 2 · 装一件货，数一数

cargo = ["茶叶"] cargo.append("云锦") print(len(cargo))

append 把「云锦」装到队尾，列表变成 ["茶叶", "云锦"]，len 数出 2。注意 append 是「加一件」，不是「替换」——原来的茶叶还在。

练 3 · 这段循环打印几行？

for x in ["A", "B"]: print(x)

for-in 遍历：列表里有 2 项，循环就跑 2 圈，每圈 x 依次是 "A"、"B"，各打印一行。列表有几个元素，遍历就跑几圈——不用自己数圈数。
