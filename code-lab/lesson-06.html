while 与猜数字

for 循环知道跑几圈，while 循环只认条件：「条件成立就继续」。配上 random 随机数，你就能写出经典游戏——猜数字。

课前导读

「满足条件就继续」的永动机

泄洪前控制室要倒数：3、2、1、泄洪！这就是 while 的拿手戏——只要 n > 0 成立就不停歇，每圈把 n 减 1，条件一破立即收工。for 像「跑 5 圈操场」，while 像「天黑前一直跑」。

但小心：忘了改条件变量，程序就永远停不下来，这叫死循环。这一课你还会认识 random.randint——它负责「掷骰子」，是猜数字游戏的心脏。

先懂 4 个概念

while 循环

先判断条件，成立就执行循环体，再回头判断——直到条件为 False。它和 if 的区别：if 问一次，while 反复问。

while n > 0:
    n = n - 1

循环三要素

①初值（n = 3）②条件（n > 0）③变化（n = n - 1）。缺了第 3 件，条件永远成立，循环永远不停。

n = 3      # ①
while n > 0:   # ②
    n = n - 1  # ③

random 随机数

random.randint(1, 6) 掷出一个 1 到 6 的数（两头都算）。先 import random 借工具，再调用它。

import random
r = random.randint(1, 6)

死循环与护栏

条件永远 True 的循环叫死循环，浏览器会卡住。本站运行器装了护栏：超过 10 万圈强制喊停并提醒你——真实开发可没有这层保护。

练 1 · 这个 while 打印几行？

n = 1 while n < 4: print(n) n = n + 1

n 从 1 起，条件 n < 4 成立时打印：1、2、3。n 变成 4 时条件不成立，循环停——注意 4 本身不打印。

练 2 · 忘写 n = n - 1 会怎样？

条件变量不变，条件就永远 True——这就是死循环。本站运行器有 10 万圈护栏会强制喊停，但在真实电脑上它会让程序卡死。写 while 必念三要素！

练 3 · randint(1, 6) 能掷出几？

randint 是「两端的都算」——randint(1, 6) 相当于一颗真骰子。对比 range(1, 6) 数头不数尾，两者刚好相反，别记混。
