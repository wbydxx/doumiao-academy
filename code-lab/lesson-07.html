开工前回看 4 件工具

字典：查门票

景点名做键、门票价做值，一行建好速查表。取值用 spots[name]，键打错会 KeyError。

spots = {"中山陵": 0}

函数：播报员

把「打印一天行程」打包成 plan(day, spot)，参数喂什么它播什么——调用两次就排两天。

def plan(day, spot):
    print(f"第 {day} 天：{spot}")

for-in：遍历

for cost in costs 让 cost 依次变成列表里的每一项，循环体里做累加。

for cost in costs:
    total = total + cost

组合拳心法

先想「要什么输出」，再倒推「用哪件工具」：查信息→字典；重复说话→函数；逐笔记账→for。

毕业挑战，看你真的出师了吗

练 1 · 存「景点 → 门票」该用哪件工具？

「名字查价格」是一对一映射，正是字典的主场。列表适合「一串同类的排队站」，字典适合「贴标签的抽屉」。

练 2 · 这个调用会打印什么？

def plan(day, spot): print(f"第 {day} 天：{spot}") plan(2, "夫子庙")

调用 plan(2, "夫子庙") 时，2 传给 day、"夫子庙" 传给 spot，按位置一一对应。f-string 再把两个参数填进模板——函数体执行，打印出播报词。

练 3 · 这段累加在干嘛？

total = 0 for cost in costs: total = total + cost

这是最经典的「累加器」套路：total 从 0 起步，每圈把一项 cost 加进去，循环结束就是总和。「零起手、圈圈加」——记住它，求和题全是它。
